# 个人设置手工验收

本次受影响的 UI：`/profile` 个人设置页、后台侧栏账户区域、后台评论头像与昵称、评论区登录用户入口及评论头像/网站链接。按项目约定不新增 UI 单元测试或主动执行 E2E；以下项目由人工验收。

上线前备份数据库并运行 `bun run db:migrate`，新增 `user.website`、`user.bio` 两个可空字段。

- [ ] 未登录访问 `/profile` 显示登录表单；邮箱和 OAuth 登录后进入个人设置。
- [ ] 普通用户、无站点账号、审核员、实例管理员均可从后台“个人设置”进入；评论区点击自己的昵称在新窗口进入。
- [ ] 昵称、头像 URL、网站及简介加载正确；邮箱只读。
- [ ] 修改全部字段并保存，出现成功提示，刷新页面和重新登录后资料仍保留。
- [ ] 昵称为空/仅空格、超过 60 字、简介超过 500 字时拒绝保存；无效 URL、javascript/data 协议、含用户名密码的 URL 被拒绝，输入仍保留。
- [ ] 头像 URL 预览可见，图片失败回退到默认头像；“恢复默认头像”及清空网站/简介后保存，刷新仍为空。
- [ ] 重置修改恢复最近保存的值；未修改时保存/重置按钮禁用；保存中表单及按钮禁用。
- [ ] 未保存时点击“返回评论管理”、刷新或关闭窗口显示离开提示；取消离开后输入保留。
- [ ] 网络中断、保存失败、登录失效时显示可理解的错误，输入保留；恢复连接后可以重试。
- [ ] 已发布评论及回复显示当前昵称、头像，昵称链接到个人网站并在新窗口打开；删除评论不显示原昵称、头像或网站。
- [ ] 匿名评论仍使用原昵称和默认头像；本人邮箱及简介不出现在公开评论接口。
- [ ] 后台侧栏、评论列表及其他已打开的评论页在刷新/重新聚焦后显示更新后的资料。
- [ ] 在 360px 手机和桌面宽度检查头像表单、长昵称、长地址、错误提示及按钮，无横向溢出；键盘可访问所有操作。

服务端核查项：未登录 GET/PATCH 返回 401，停用账号拒绝访问，跨来源保存返回 403，非 JSON 保存返回 415；请求不能指定其他用户或修改权限/额度，非法字段返回 400。
