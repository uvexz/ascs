# 管理员后台手工验收

受影响页面：登录/注册页面、后台侧栏和站点添加弹窗，以及新增的系统概览、用户管理、全部站点、系统设置、邮件队列、操作日志。现有站点设置、评论管理和嵌入评论区会受到额度和停用状态的影响。

本次已用临时 SQLite 数据库直接调用服务端接口验证认证和业务逻辑；未运行 UI 单元测试、浏览器 E2E 或截图验收。

## 登录与权限

- [ ] 实例管理员登录后可以看到所有实例管理入口；站点所有者和审核员只能看到获授权的站点功能。
- [ ] 登录页面、侧栏和浏览器标题显示配置的服务名称，长名称在手机宽度不溢出。
- [ ] 关闭注册后不显示注册按钮；已有邮箱账号和 OAuth 账号仍可登录，新邮箱和新 OAuth 账号注册被拒绝。
- [ ] 停用用户后所有设备登录失效，不能登录、创建站点或使用该账号发表评论；启用后可重新登录。

## 用户和站点

- [ ] 用户搜索、状态筛选、分页、空状态、加载失败重试正常。
- [ ] 创建用户后可用初始密码登录；重复邮箱和不合规密码显示错误。
- [ ] 编辑昵称、额度和管理员角色成功；不能停用自己、删除自己或取消自己的管理员权限。
- [ ] 撤销登录有确认，其他设备立即需要重新登录。
- [ ] 用户领取注册时的默认额度；修改默认额度不改变已有账号；额度为 0 时不能创建站点。
- [ ] 额度内用户可以创建站点，到达额度后创建被拒绝；站点仍需完成域名验证。
- [ ] 全部站点能搜索、筛选；停用后评论区不能读取、发表评论或点赞，管理员仍可审核历史内容。
- [ ] 转移站点给有效且额度充足的账号后，原所有者失去权限，新所有者可管理；额度不足时保留原所有权。
- [ ] 删除用户要求输入邮箱确认；拥有站点的账号必须先转移；删除后历史评论显示“已注销用户”，不破坏回复树。

## 系统配置

- [ ] 修改基本配置和 SMTP 后保存，刷新后值仍保留。
- [ ] SMTP 密码不回显；留空保存保留原值；勾选清除后删除原值；已启用且必需凭据缺失时保存失败。
- [ ] 未保存时切换页面、站点或关闭标签页有提示；保存期间不能重复提交。
- [ ] 两个管理员同时编辑，后保存的过期版本被拒绝，能刷新后重新编辑。
- [ ] 真实 SMTP：465 隐式 TLS、587 STARTTLS、发件邮箱和授权码配置正确时收到测试邮件；错误凭据出现可理解的错误。
- [ ] 系统设置仅显示基本配置、SMTP 和邮件连接测试，移除存储配置后桌面与手机布局正常。
- [ ] 升级前已保存的系统配置可以正常读取；修改并保存后基本配置和 SMTP 仍然有效。

## 邮件和操作日志

- [ ] 邮件队列可筛选待发送、已发送和重试耗尽；显示收件人、主题、次数和状态。
- [ ] 重试耗尽邮件可重新排队；发送中和已发送邮件不能重新排队。
- [ ] “立即发送一批”最多处理 20 封；未配置 SMTP 时显示提示；真实邮件送达需检查收件箱。
- [ ] 创建/编辑/删除用户、撤销登录、保存配置、创建/转移/启停站点、连接测试和邮件重试均出现操作日志。
- [ ] 手机与桌面下侧栏可访问，列表动作可换行，长邮箱/域名不遮挡按钮，弹窗可用键盘操作。
