# Kumo 链接样式复核

本次复核覆盖个人设置、后台导航与评论列表、评论区、密码重置、错误页、Markdown 链接及账户头像入口。按 kumo-design 核对正文与控件字号、字重、字距、交互颜色过渡、图标对齐、边界与阴影、Dialog 挂载及窄屏布局。

链接采用 Kumo `plain` 的视觉样式，并遵循用户要求：所有文字链接无下划线，默认使用 Kumo 主题链接色，悬停即时采用链接色的 70% 透明度；不添加颜色过渡。键盘操作保留清晰的焦点轮廓。导航、品牌及头像入口继续使用各自的背景/轮廓反馈。

其他已修复项：

- 链接默认样式、标题/段落的 margin 与控件的 font 基础重置放在 `@layer base`，允许工具类正常生效。正文常用字号 token 固定为 14px，避免 14px 根字号把 Kumo 的提示文字缩小。
- 重置密码后的返回入口、评论区底部 ASCS、文章地址和 Markdown 链接统一使用文字链接样式。
- `/profile` 返回链接的文字和箭头继承同一颜色；嵌入评论区的用户名保留新窗口图标、完整昵称说明和截断，标题与退出按钮禁止被挤缩。
- 账户头像入口增加悬停轮廓和圆角焦点区域。
- 默认头像不再以内联尺寸覆盖手机端 CSS；个人设置中指定的 64px 预览仍保留。
- 个人设置的头像与地址输入在窄屏上下排列；简介没有校验错误时隐藏空提示行。

浏览器视觉与交互验收尚未执行，不以类型检查或构建通过替代。
